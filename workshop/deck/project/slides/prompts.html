Ideias de pedido

“Um gato de uma linha só.”

“Meu nome em letra cursiva, bem grande.”

“Uma espiral que termina em estrela.”

“Uma paisagem: sol, montanha e rio.”

Se saiu torto, peça ajuste: “maior”, “mais para a esquerda”, “sem a segunda estrela”.

Cada grupo escolhe um pedido, ou inventa o seu. Pedir sempre para ensaiar antes. Se o desenho sair do papel, o código recusa e a LLM corrige.
