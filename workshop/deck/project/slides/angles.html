Cada ponto do papel tem dois ângulos

ponto (70, 165) mm

θ1 = 146° θ2 = -80°

ponto (118, 196) mm

θ1 = 118° θ2 = -57°

ponto (172, 158) mm

θ1 = 111° θ2 = -83°

Você pede uma posição (x, y). O Plotter calcula os ângulos (cinemática inversa) e o Arduino gira os servos. A área tracejada é a folha onde dá para desenhar.

Os ângulos aqui são calculados pelo mesmo código do braço (ik em kinematics.py), para os três pontos mostrados.
